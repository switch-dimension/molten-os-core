# Report output — `molten-docs/validate/product-score-N.md`

## Output directory (required)

All validation reports live under **`molten-docs/validate/`** at the workspace root.

1. **Create** `molten-docs/validate/` if it does not exist (`mkdir -p molten-docs/validate`).
2. **Find** existing `product-score-*.md` only in that directory (not `.planning/`, not workspace root).
3. **Next file:** `molten-docs/validate/product-score-1.md`, or highest `N` + 1.
4. **Never overwrite** an existing file.
5. Record the full relative path in frontmatter when linking prior files (e.g. `prior_score_file: molten-docs/validate/product-score-1.md`).

## After writing (chat)

**Do not** repeat the verdict, scorecard, red flags, experiment, or next steps in chat — they belong in the report.

Reply with **only** a pointer to the file, for example:

> Review your evaluation in **`molten-docs/validate/product-score-N.md`** — hypothesis, verdict, scorecard, red flags, riskiest-assumption experiment, and recommended next steps are all there.

You may add one short line if the user must do something outside the file (e.g. run the next `AskQuestion` round). Otherwise, stop after the pointer.
